# PRD — BetterDictation

## 问题

macOS 自带听写：识别质量一般、不支持自定义词表、中途不能看实时结果、且绑定在系统快捷键上无法替换引擎。用户已有的讯飞私有 ASR 链路（vow 项目已验证）质量更好，但只在 Windows 宿主上可用。

## 目标

在 macOS 上提供一个**接管 F5 的独立听写器**，把系统听写的触发方式、交互形态保留下来，把引擎换成自己的。

## 用户故事

1. 我在终端 / 编辑器 / 浏览器里写东西，按 F5 就能说话，再按 F5 文本出现在光标处。
2. 我不想登录任何账号、不想配置 API Key，装完就能用。
3. 我说话时能看到已经识别出的部分，确认它在工作。
4. 我按 Esc 能立刻放弃这次输入，不留半截文本。
5. 我不想它抢我的焦点、动我的剪贴板。

## 非目标

- 不做多语言切换（跟随讯飞端点行为）。
- 不做语音命令 / 编辑指令。
- 不替代虚拟麦克风链路（那是 vow 的职责）。
- 不做 App Store 分发（私有协议 + ad-hoc 签名）。

## 验收

| # | 标准 |
|---|------|
| 1 | 首次运行按一下 F5 即完成绑定，重启后绑定保持 |
| 2 | 按下 F5 后 < 300ms 开始推流；浮层可见 |
| 3 | 终稿在松手后 < 1.5s 注入焦点窗口，中文无乱码 |
| 4 | 注入不修改剪贴板 |
| 5 | Esc 取消后不注入任何文本 |
| 6 | 辅助功能权限在运行期授予后，无需重启即生效 |
